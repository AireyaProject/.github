## About Aireya

有些东西在被做出来之前，  
可能只是一句话、一张草图，或者某个突然冒出来的念头。

**Aireya** 是一个由学生组成的创作型兴趣社团。

我们不把自己限定成编程社、游戏社或者电子社。  
在这里，一个项目可以是一款小游戏、一段视觉小说、一个自己想用的软件，
一台小型电子设备，也可以是某种现在还没有名字的东西。

我们想做的，只是给这些想法一个真正发生的地方。

> **让还没有名字的想法，慢慢变成可以留下来的东西。**

项目的方向并不是固定的。

有人有一个故事，  
有人想试一个奇怪的游戏机制，  
有人觉得现有的软件不好用，  
也有人只是突然很想把某个东西做出来。

如果这个想法值得试试，我们就可以从那里开始。

## How we work

我们喜欢从一句：

> **“要不要试试看？”**

开始。

然后把它慢慢缩小，直到变成一个现在真的可以开始做的东西。

**Idea → Team → Prototype → Finish → ...**

我们不太喜欢让项目永远停留在“以后一定会做”。

所以相比一开始规划一个巨大的作品，我们更愿意先完成一个很小、
但已经可以运行、游玩或者实际使用的版本。

如果做完以后大家依然喜欢它——

那就让它继续长大。

## You don't have to code

Aireya 并不只有程序员。

一个项目可能需要：

| | |
|---|---|
| `CODE` | 程序开发 |
| `ART` | 美术与视觉 |
| `WRITING` | 剧情与文字 |
| `DESIGN` | UI / UX / 项目设计 |
| `HARDWARE` | 电子与硬件 |
| `TESTING` | 测试、资料与整理 |

不会编程也完全没关系。

你可以做自己已经喜欢的东西，  
也可以因为某个项目，第一次试试以前从来没有接触过的方向。

## Our little rule

我们没有很多复杂的规则。

不过有一件事情很重要：

**如果接下了一件事，就认真对待它。**

不会可以学。  
做错可以重新来。  
计划也随时可以改。

只是如果遇到了问题，希望你愿意告诉其他人，
而不是让项目悄悄停在那里。

Aireya 希望大家可以轻松地一起做东西，

但也希望最后真的能留下点什么。
